# SSD-002: 측면 장애물 회피

- **연관 UC**: UC-002
- **관련 요구사항**: FR-02, SR-03

## 시스템 시퀀스 다이어그램

```mermaid
sequenceDiagram
    actor OS as ObstacleSensor
    participant SYS as System
    actor CM as CleaningMotor
    actor DM as DriveMotor

    Note over OS,DM: UC-001 실행 중

    OS->>SYS: frontObstacleDetected()
    SYS->>CM: stopCleaning()
    SYS->>DM: stop()

    OS->>SYS: sideStatus(available)
    SYS->>DM: turn(direction)

    SYS->>CM: startCleaning(Normal)
    SYS->>DM: moveForward()

    Note over OS,DM: UC-001 기본 흐름 복귀
```

## 시스템 오퍼레이션 목록

| 오퍼레이션 | 설명 |
|-----------|------|
| `frontObstacleDetected()` | 전방 장애물 감지 신호를 수신한다 |
| `sideStatus(available)` | 여유 공간이 있는 방향(Direction)의 목록을 수신한다 |
