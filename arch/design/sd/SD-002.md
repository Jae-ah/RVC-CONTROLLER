# SD-002: 측면 장애물 회피

- **연관 UC**: UC-002
- **연관 SSD**: SSD-002

## 시퀀스 다이어그램

```mermaid
sequenceDiagram
    actor OS as ObstacleSensor
    participant RVC as RVCController
    participant NAV as NavigationController
    participant CLN as CleaningController
    actor CM as CleaningMotor
    actor DM as DriveMotor

    Note over OS,DM: UC-001 실행 중

    OS->>RVC: frontObstacleDetected()
    RVC->>CLN: stopCleaning()
    CLN->>CM: stopCleaning()
    RVC->>NAV: stop()
    NAV->>DM: stop()

    OS->>RVC: sideStatus(available)
    RVC->>NAV: turn(available)

    alt available = {LEFT, RIGHT}
        NAV->>DM: turn(random Direction)
    else available = {LEFT}
        NAV->>DM: turn(LEFT)
    else available = {RIGHT}
        NAV->>DM: turn(RIGHT)
    end

    RVC->>CLN: startCleaning()
    CLN->>CM: startCleaning(NORMAL)
    RVC->>NAV: moveForward()
    NAV->>DM: moveForward()

    Note over OS,DM: UC-001 기본 흐름 복귀
```

## 설계 노트

- `NavigationController.turn(available)` — `Direction` 목록을 받아 방향 선택 로직(랜덤 포함)을 NavigationController 내부에서 수행한다 (SRP)
- 예외 흐름 E1 (좌·우 모두 막힘): `sideStatus([])` 수신 시(available이 빈 리스트) RVCController가 UC-003 흐름으로 전환한다
