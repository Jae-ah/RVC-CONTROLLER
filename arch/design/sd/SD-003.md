# SD-003: 삼면 장애물 후진 회피

- **연관 UC**: UC-003
- **연관 SSD**: SSD-003

## 시퀀스 다이어그램

```mermaid
sequenceDiagram
    actor OS as ObstacleSensor
    participant RVC as RVCController
    participant NAV as NavigationController
    participant CLN as CleaningController
    actor CM as CleaningMotor
    actor DM as DriveMotor

    Note over OS,DM: UC-001 실행 중

    OS->>RVC: allSidesBlocked()
    RVC->>CLN: stopCleaning()
    CLN->>CM: stopCleaning()
    RVC->>NAV: moveBackward()
    NAV->>DM: moveBackward()

    loop available가 빌 때까지
        OS->>RVC: sideStatus(available)
    end

    RVC->>NAV: stop()
    NAV->>DM: stop()

    RVC->>NAV: turn(available)

    alt available = {LEFT, RIGHT}
        NAV->>DM: turn(random Direction)
    else available = {LEFT}
        NAV->>DM: turn(LEFT)
    else available = {RIGHT}
        NAV->>DM: turn(RIGHT)
    end

    RVC->>NAV: moveForward()
    NAV->>DM: moveForward()
    RVC->>CLN: startCleaning()
    CLN->>CM: startCleaning(NORMAL)

    Note over OS,DM: UC-001 기본 흐름 복귀
```

## 설계 노트

- 청소 재개(`startCleaning`)는 전진 시작 이후에 호출한다 (UC-003 기본 흐름 8→9 순서)
- 후진 중 루프를 탈출하는 조건: `available`이 비어 있지 않을 때
- 방향 선택 로직은 SD-002와 동일하게 NavigationController 내부에서 수행한다
